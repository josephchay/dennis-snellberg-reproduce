# Portfolio Recreation - Dennis Snellberg

## About

Recreation attempt of Dennis Snellberg portfolio https://dennissnellenberg.com/

## Development

Clone the repository:

```bash
git clone https://github.com/josephchay/dennis-snellberg-recreate
```

Navigate to the project directory:

```bash
cd dennis-snellberg-recreate
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
