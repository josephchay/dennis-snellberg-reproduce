# Folio 2024 of Joseph Chay

---

## About

The 2024-iteration of the portfolio of Joseph Chay, documenting his bio and experiences, demonstrating his skillsets, as well as showcasing his past works.

[![Live-Site](https://img.shields.io/website?url=https://josephchay.netlify.app&style=for-the-badge)](https://josephchay.netlify.app/)

## Development

Clone the repository:

```bash
git clone https://github.com/josephchay/folio-2024
```

Navigate to the project directory:

```bash
cd folio-2024
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
